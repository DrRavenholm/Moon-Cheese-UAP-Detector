# Security policy

Moon Cheese UAP Detector is in pre-v1.0 development. Do not post passwords, API tokens, access credentials, private signing keys, full system configuration files or private recordings in GitHub Issues.

If GitHub's **Private vulnerability reporting** feature has been enabled for this repository, use it to report security problems privately. Otherwise, contact the maintainer privately before publishing vulnerability details.

The project does not require Cloudflare credentials or GitHub account credentials to be submitted to the repository. Each deployed detector manages its own credentials locally.
